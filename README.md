# Basit-TCP-Chat-Uygulamas-stemci-sunucu-mesajla-ma
Amaç: İki bilgisayar veya iki terminal arasında TCP üzerinden mesajlaşma sağlamak.
Çalıştırma Sırası (İki Terminal Gerekli):
İlk terminalde (Sunucu tarafı):
python server.py
→ “Sunucu dinliyor...” yazısı çıkar.

İkinci terminalde (İstemci tarafı):
python client.py
→ “Sunucuya bağlanıldı.” yazar.

Artık mesajlaşabilirsiniz 🎉

🗣️ Örnek iletişim:

İstemci terminali:
Sen: Merhaba
Sunucu: Merhaba istemci!


Sunucu terminali:
İstemci: Merhaba
Sen: Merhaba istemci!
